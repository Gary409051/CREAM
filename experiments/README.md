# Experiments

No experiment has run. The [protocols](../docs/EXPERIMENT_PROTOCOLS.md) define proposed E1–E4 and their evidence limits.

- [preregistrations](preregistrations/README.md): dated immutable protocols and safe resolved configs after review/freeze.
- [reports](reports/README.md): reviewed actual results, deviations, negative findings and gate decisions.
- [runs](runs/): ignored local run logs, predictions and artifacts; not public results by default.

Use stable experiment/run IDs without identities. Link a report to its frozen protocol, commit/config/input hashes, environment and complete run set. See [REPRODUCIBILITY](../docs/REPRODUCIBILITY.md). Do not fill report tables with desired effect sizes or planned participant counts.
